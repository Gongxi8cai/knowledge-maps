std::optionalSTL/库std::optional<int> f();表达「可能没有值」，替代哨兵值进阶+异常与错误

功能关键字 / API用来做什么阶段交叉
定义与访问控制关键字class Buch { public: ... private: ... };class 默认 private，struct 默认 public入门—
构造函数STL/库Buch(std::string t, int s)保证对象一出生就合法入门—
成员初始化列表写法Buch(...) : titel_(t), seiten_(s) {}比在函数体里赋值更早、更快，const 成员必须这样常用—

RAII 与智能指针RAII

资源在构造时获取、在析构时释放——C++ 不用 finally 也能异常安全。

功能关键字 / API用来做什么阶段交叉
RAII 是什么写法把资源包进对象，靠析构自动释放std::vector、std::string、std::fstream 都是入门类与对象
unique_ptrSTL/库auto p = std::make_unique<T>(args);独占所有权，不能拷贝只能移动——默认首选入门内存与性能
shared_ptrSTL/库auto p = std::make_shared<T>(args);引用计数共享所有权；有原子计数开销常用—
weak_ptrSTL/库std::weak_ptr<T> w = sp;打破循环引用；用 lock() 取临时 shared_ptr进阶—
make_unique / make_sharedSTL/库别写 new异常安全 + 一次分配（shared）常用—
所有权表达STL/库unique_ptr = 拥有，T* = 借用，T& = 必存在函数签名就用这个约定说话进阶函数
std::moveSTL/库vec.push_back(std::move(s));只是转成右值引用，真正搬东西的是移动构造进阶内存与性能
noexcept 与移动关键字移动构造标 noexcept否则 vector 扩容时不敢用移动，只能拷贝进阶+STL 容器
常见泄漏源STL/库裸 new、new[] 配 delete、循环 shared_ptr用容器/智能指针替掉它们常用—

STL 容器Container

先用容器，再谈算法：vector 是默认，map 要排序、unordered_map 要速度。

功能关键字 / API用来做什么阶段交叉
std::vectorSTL/库std::vector<int> v{1,2,3};动态数组，连续内存、随机访问——默认选它入门内存与性能
std::stringSTL/库std::string s = "abc";自带长度、自动扩容，别再用 char[]入门字符串与流
std::map / unordered_mapSTL/库std::map<K,V>：有序 O(log n)；unordered_map：哈希平均 O(1)要顺序遍历用 map，要快用 unordered常用—
std::set / unordered_setSTL/库std::set<int> s;去重 + 存在性判断常用—
std::array / std::dequeSTL/库std::array<int,5>、std::deque<T>定长数组有边界检查；deque 两端插入快进阶—
迭代器关键字for (auto it = v.begin(); it != v.end(); ++it)容器的通用游标；cbegin 只读常用算法与 Lambda
失效规则STL/库push_back 后指针/迭代器可能全部失效循环里改容器要小心，reserve 能减少重分配进阶+内存与性能
emplace_back vs push_backSTL/库v.emplace_back(args...) 就地构造省一次临时对象进阶内存与性能
size() 返回 size_tSTL/库for (size_t i = 0; i < v.size(); ++i)和 int 混比会有符号警告常用类型与初始化

备注 · 易错点 / 取舍 / 顺序

1
new 之后一定要有对应的 delete
除非它交给了智能指针或容器。现代 C++ 里裸 new 几乎只出现在实现内部。
2
多态基类的析构函数必须 virtual
否则 delete基类指针时派生类析构不执行——这是最经典的泄漏。
3
std::move 不移动任何东西
它只是把左值转成右值引用；真正搬资源的是移动构造/移动赋值。
4
别 return std::move(local);
会阻止返回值优化（RVO），反而更慢。直接 return local;。
5
std::endl 会 flush
循环里输出用它很慢，用 '\n'。
6
size() 是 size_t（无符号）
for (int i = 0; i < v.size(); ++i) 会有符号比较警告，用 size_t。
7
vector<bool> 是特化，不是普通 vector
它按位存储，&v[0] 不合法；要布尔数组用 std::vector<char> 或 bitset。
8
头文件里不要 using namespace std;
会把整个标准库名字倒进所有包含它的文件。
9
push_back 后旧指针/迭代器可能失效
循环中改容器前先想清楚；reserve 能减少重分配。
10
编译慢的常见原因
头文件引太多、模板太重、没开并行编译（make -j）。前置声明和 -O2 只在发布时用。
11
学 C++ 的顺序
①类与 RAII ②容器与算法 ③继承与多态 ④移动语义 ⑤模板。C++ 不能像 Python 那样「边写边学」。
12
和 Java 的关键差别
C++ 没有垃圾回收、有真正的值语义与析构函数、模板在编译期展开（Java 泛型是类型擦除）。
