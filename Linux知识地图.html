rwx 的含义选项/语法文件：读内容/写内容/执行；目录：列目录/建删文件/进入目录的 x 是「能不能 cd 进去」常用—
数字法命令chmod 644 a.txt、chmod 755 脚本.sh4=r 2=w 1=x，三组相加入门—
符号法命令chmod u+x 脚本.sh、chmod go-w a.txtu 属主、g 组、o 其他、a 全部常用—

umask命令umask 看默认掩码（常见 022）新建文件默认 644、目录 755进阶—
sudo命令sudo 命令临时以 root 执行；别 sudo 一切常用软件安装
执行脚本要两件事命令有 x 权限 + 有 shebang（或 bash 脚本.sh）Permission denied 先查这两条常用脚本与自动化

文本处理三剑客Textwerkzeuge

grep 找行、sed 改行、awk 按列算；配上 sort/uniq 能一行完成统计。

功能关键字 / API用来做什么阶段交叉
grep 搜行命令grep -i -n -r "关键词" .-i 忽略大小写、-n 行号、-r 递归、-v 反选入门查看与编辑
grep 正则命令grep -E "^[0-9]+"-E 用扩展正则；-o 只输出匹配部分常用—
sed 替换命令sed 's/旧/新/g' a.txt、sed -i 's/旧/新/g' a.txt-i 直接改文件（先备份！）常用—
sed 选行命令sed -n '10,20p' a.txt打印第 10–20 行常用—
awk 取列命令awk '{print $1, $3}' a.txt$0 整行、$NF 最后一列进阶—
awk 条件与统计命令awk -F, '$3 > 100 {s+=$3} END {print s}'分隔符 -F、模式 + 动作进阶+—
cut命令cut -d, -f2 a.csv简单取列；字段里含分隔符就不可靠常用—
sort命令sort -n、sort -k2,2nr、sort -u-n 数值、-k 指定列、-r 逆序常用—
uniq命令uniq -c（必须先 sort）只合并相邻重复行常用—
一行做词频命令cat a.txt | tr -cs 'A-Za-z' '\n' | tr 'A-Z' 'a-z' | sort | uniq -c | sort -k1,1nr -k2,2 | head -3清非字母 → 统一小写 → 排序 → 计数 → 再排序进阶重定向与管道

备注 · 易错点 / 取舍 / 顺序

1
rm -rf 没有回收站
执行前先 ls 同样的通配符，看清到底匹配了什么。rm -rf $VAR/ 在 VAR 为空时等于 rm -rf /。
2
cp 与 mv 覆盖不提示
加 -i 或 alias cp='cp -i'。
3
> 会立刻清空目标文件
哪怕命令随后失败。要保留就先写临时文件再 mv。
4
2>&1 的位置有讲究
命令 > a.log 2>&1 才是「都进同一个文件」；顺序反过来只重定向了 stderr。
5
tail -f 看的是「新写入」
日志轮转后要 tail -F。
6
目录的 x 权限
没有 x 就不能 cd 进去，即使有 r。
7
sudo 不是万能钥匙
改 PATH、装 Python 包都不该用 sudo。
8
SSH 断了任务就死
长任务用 nohup ... & 或 tmux/screen。
9
cron 里没有你的 PATH
脚本里用绝对路径，或在开头自己 export PATH。
10
find 比 ls | grep 可靠
文件名里有空格/换行时尤其明显。
11
日志时间不对
先 timedatectl 查时区，再看服务自己的时区配置。
12
学 Linux 的顺序
①路径与文件操作 ②权限 ③管道与重定向 ④grep/sed/awk ⑤进程与日志 ⑥ssh 与脚本。
