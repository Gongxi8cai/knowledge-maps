容器Container

list 有序可改、dict 查得快、set 去重、tuple 不可变——先选对容器。

功能关键字 / API用来做什么阶段交叉
list内置a = [1, 2, 3]；append pop insert remove有序、可重复、随机访问 O(1)入门—
dict内置d = {"a": 1}；d.get(k, 默认)键值映射，查找平均 O(1)入门—
set内置s = {1, 2}；| & -去重与集合运算；元素必须可哈希常用—
tuple内置t = (1, 2)；能当 dict 的键不可变，适合固定结构（坐标、返回值）常用类型与变量
切片写法a[1:3]、a[::-1]、a[::2]返回新对象；切片赋值可替换一段常用—
推导式写法[x*x for x in a if x > 0]列表/字典/集合推导，比 for+append 快且短常用迭代器与生成器
排序内置sorted(a)、a.sort(key=lambda x: -x)sorted 返回新列表；同值稳定排序常用函数
解包写法a, b = b, a；first, *rest = a交换变量、取剩余项常用—
in 与计数关键字x in a、a.count(x)list 的 in 是 O(n)，set/dict 是 O(1)入门—
嵌套与共享写法[[0]*3]*3 三个内层是同一个列表要用 [[0]*3 for _ in range(3)]进阶类型与变量

备注 · 易错点 / 取舍 / 顺序

1
默认参数只在定义时求值一次
def f(a, buf=[]) 的 buf 是所有调用共享的同一个列表；用 buf=None。
2
== 比内容，is 比身份
只有和 None/True/False 比较时才用 is。
3
[[0]*3]*3 不是二维数组
三个内层是同一个列表；要 [[0]*3 for _ in range(3)]。
4
list.sort() 返回 None
它就地排序；要新列表用 sorted()。
5
遍历时别改列表
用 for x in a[:] 或新建列表；否则会跳过元素。
6
except: 会连 Ctrl+C 一起吞
至少写 except Exception:，最好指明类型。
7
读文件一定写 encoding="utf-8"
Windows 默认 gbk，德语变音符号与 emoji 会炸。
8
import 只在第一次执行
模块级代码会被缓存；要刷新用 importlib.reload（调试才用）。
9
浮点不要 ==
abs(a-b) < 1e-9；要精确小数用 decimal。
10
字符串拼接别用 += 循环
O(n²)；用 "".join(parts)。
11
学 Python 的顺序
①容器与循环 ②函数与参数 ③文件与异常 ④类 ⑤模块与 venv ⑥生成器与装饰器。
12
Python 不是「慢」，是「你写慢了」
热点用 numpy / 内置函数 / 生成器，别急着上 C 扩展。
