编译与工具链Werkzeuge

把源码变成能跑的程序：预处理 → 编译 → 汇编 → 链接。

功能关键字 / API用来做什么阶段交叉
四步流水线命令行gcc -E/-S/-c | .i → .s → .o → 可执行预处理展开宏与头文件，编译成汇编，汇编成目标文件，链接成 exe入门预处理器
常用选项命令行-std=c17 -Wall -Wextra -g -O2指定语言标准、开警告、留调试信息、开优化入门调试
只要目标文件命令行gcc -c a.c → a.o多文件项目先各自编译，再一起链接常用头文件
链接多个文件命令行gcc a.o b.o -o app把多个 .o 合成一个程序；缺 main 或重复定义会在这里报错常用函数
链接库命令行-lm、-I路径、-L路径 -l名字数学库要显式 -lm；-I 加头文件搜索路径常用标准库
调试版与发布版命令行-g -O0 vs -O2调试时别开优化，否则断点会「跳行」常用调试
Sanitizer命令行-fsanitize=address,undefined运行时抓越界、泄漏、未定义行为——学习期强烈建议开进阶内存管理
Makefile命令行make + 目标: 依赖 + Tab 命令只重编改过的文件，不用每次手敲一长串进阶—
看编译器到底做了什么命令行gcc -S -masm=intel把 C 翻成汇编，理解指针和数组的真实代价进阶+指针

类型与变量Datentypen

C 的类型很薄：只有整数、浮点、指针三类底子，其余都是组合。

功能关键字 / API用来做什么阶段交叉
整数类型关键字char short int long long long宽度随平台变；要固定宽度用 int8_t…int64_t入门—
有无符号关键字unsigned int、size_tsize_t 是长度与下标的正确类型；混用有符号会出坑常用字符串
浮点C 库float（约 7 位）、double（约 15 位）默认用 double；比较要用误差而不是 ==入门—
sizeof关键字sizeof x、sizeof(int)结果是字节数，类型是 size_t；数组传参后会失效常用数组
取值范围C 库<limits.h>、<float.h>INT_MAX、INT_MIN、DBL_EPSILON常用—
类型转换C 库(double)i、隐式提升整数相除先转浮点，否则 7/2 == 3常用表达式
const关键字const double PI = 3.14;只读；指针的 const 位置决定「谁能改」常用指针
static关键字函数内 static int n;函数内：只初始化一次、跨调用保留；文件作用域：外部不可见进阶函数
枚举关键字enum Farbe { ROT, GRUEN };给整数起名字，比 #define 有类型检查常用结构体

运算符与表达式Ausdrücke

算术、比较、位运算；C 的优先级和隐式转换是错误高发区。

功能关键字 / API用来做什么阶段交叉
算术与取模写法+ - * / %整数除法会截断；% 只能用于整数入门类型与变量
自增自减写法i++、++i在表达式里混用是 UB 高发点，单独一行用最稳常用—
比较与逻辑写法== != < > && || !&&/|| 会短路；别把 = 写成 ==入门控制流
位运算写法& | ^ ~ << >>开关标志、掩码、快速乘除 2 的幂；无符号移位才安全进阶—
复合赋值写法+= -= *= /= %= &= |= <<=a += b 等价 a = a + b入门—
三元运算符C 库cond ? a : b短小的二选一；嵌套三层就该改 if常用控制流
逗号运算符写法a = (b++, c)从左到右求值，整体取最后一个——除 for 里外少用进阶—
优先级写法* 高于 +，& 低于 ==记不住就加括号，别赌常用指针
隐式整型提升关键字char + char → int混合有符号/无符号时结果可能反直觉（-1 > 0u 为真）进阶+类型与变量

控制流Kontrollfluss

分支与循环；C 的 switch 和 break 语义要记清。

功能关键字 / API用来做什么阶段交叉
if / else if / else关键字if (x > 0) { … }条件里别写赋值；浮点不要直接判等入门表达式
switch关键字switch (n) { case 1: … break; default: … }只支持整数与枚举；忘了 break 会「贯穿」常用类型与变量
for关键字for (int i = 0; i < n; i++)计数循环首选；三个部分都可空入门数组
while关键字while (cond) { … }条件先判，可能一次都不执行入门—
do-while关键字do { … } while (cond);至少执行一次；读输入时常配合 scanf 返回值常用输入输出
break / continue关键字break; continue;跳出整个循环 / 跳过本次入门—
goto关键字goto fehler;只推荐用于「多层出错统一清理」，别做普通跳转进阶+内存管理
提前返回关键字if (!ok) return -1;把异常情况顶到前面，减少嵌套层次常用函数

函数Funktionen

C 只有值传递；要改外面的东西，必须传地址。

功能关键字 / API用来做什么阶段交叉
定义与调用关键字int add(int a, int b) { return a + b; }参数与返回值都有类型；没有默认参数入门—
原型声明关键字int add(int, int);放在 .h 或文件顶部，让编译器先知道签名常用头文件
值传递写法f(x) 传的是副本函数内改参数不影响调用者——这是 C 最重要的直觉入门指针
返回值与错误码关键字int rc = f(); if (rc != 0) …C 没有异常，用返回值和 errno 报错常用标准库
递归关键字int fak(int n) { return n ? n * fak(n-1) : 1; }要有终止条件；深度受栈大小限制常用内存
static 函数关键字static void helper(void)只在本文件可见，避免命名冲突进阶编译
变参函数C 库<stdarg.h>：va_list/va_start/va_arg写自己的 printf 风格函数进阶+输入输出
函数指针关键字int (*cmp)(const void*, const void*)把「行为」当参数传，qsort 就这么用进阶指针
多处返回关键字return 可以出现在任意位置配合 goto cleanup 管理资源释放进阶内存管理

数组与字符串Arrays und Strings

C 的数组不知道自己的长度，字符串靠 \0 结尾——一切越界都不报错。

功能关键字 / API用来做什么阶段交叉
一维数组关键字int a[5] = {1,2,3};未写的元素自动为 0；长度必须在编译期确定（或 C99 VLA）入门—
二维数组关键字int m[3][4]内存里是连续的一整块，行优先常用指针
数组长度关键字sizeof a / sizeof a[0]只在定义所在的函数里有效；传参后失效常用函数
越界写法a[n] 写出界不报错、静默改坏别的变量——最难查的 bug常用内存管理
strlenC 库size_t strlen(const char *s)不含结尾 \0入门指针
复制与拼接C 库strcpy/strncpy/strcat/strncatstrncpy 可能不补 \0，优先 snprintf常用输入输出
比较C 库strcmp(a,b)返回 0 表示相等；不能写 if (a == b)入门—
安全的格式化C 库snprintf(buf, sizeof buf, "%s", s)永远给长度，避免溢出常用内存管理
切分C 库strtok(s, ",")、strtok_r会修改原字符串；多线程用 _r 版进阶标准库
字符判断C 库<ctype.h>：isdigit/isalpha/toupper注意传 unsigned char常用—

指针Zeiger

指针就是「存地址的整数」；C 的威力与危险都从这里来。

功能关键字 / API用来做什么阶段交叉
取地址与解引用写法&x、*pp 存地址，*p 取那个地址上的值入门—
声明读法关键字int *p; 读作「p 是指向 int 的指针」多个指针要 int *a, *b; 而不是 int* a, b;入门类型与变量
NULL关键字int *p = NULL;用前判空；解引用空指针直接崩入门内存管理
指针算术C 库p + 1 前进 sizeof(*p) 字节数组遍历、切片都靠它常用数组
数组退化为指针写法f(a) 里的 a 就是 &a[0]所以函数里拿不到数组长度常用函数
void *关键字void *p = &x;通用地址容器（malloc 返回它）；不能直接解引用进阶内存管理
指向指针关键字char argv、int m字符串数组、二维动态数组进阶数组
const 与指针关键字const char *p vs char * const p前者：指向的内容不可改；后者：指针本身不可改进阶类型与变量
函数指针关键字int (*f)(int) = &g;回调、表驱动、qsort 比较器进阶+函数
指针的坑写法野指针、悬空指针、类型不匹配free 后置 NULL；开 sanitizer常用内存管理

内存管理Speicher

栈是自动的、堆是手动的；手动就意味着会泄漏、会双重释放。

功能关键字 / API用来做什么阶段交叉
栈 vs 堆C 库局部变量在栈、malloc 在堆栈小（几 MB）且自动回收；堆大但要自己 free入门—
mallocC 库void *malloc(size_t n)分配 n 字节，内容未初始化；失败返回 NULL入门指针
callocC 库calloc(n, size)分配并清零——数组首选常用—
reallocC 库p = realloc(p, neu)扩容；失败时原指针仍有效，别直接覆盖进阶—
freeC 库free(p); p = NULL;只能释放 malloc 系列返回的指针，且只能一次入门—
泄漏C 库分配后忘了 free长跑程序会耗尽内存；用 valgrind/ASan 找常用工具链
悬空与双重释放C 库free(p) 后又用/又 freeUB；置 NULL 是最便宜的防护常用指针
生命周期写法谁分配谁释放函数返回栈上数组的地址 = 立刻悬空常用函数
柔性数组关键字struct S { int n; int a[]; };结构体尾部跟一块变长数据，一次 malloc 搞定进阶+结构体
检查工具命令行valgrind ./app、-fsanitize=address逐字节追踪越界与泄漏进阶调试

结构体与联合Strukturen

把相关字段打包成一个类型；C 没有类，只有数据和函数分开。

功能关键字 / API用来做什么阶段交叉
定义与使用关键字struct Punkt { double x, y; };访问用 .，指针用 ->入门指针
typedef关键字typedef struct Punkt Punkt;省掉每次都写 struct常用—
初始化关键字struct Punkt p = {1.0, 2.0}; 或 {.x=1}指定初始化器更安全常用—
嵌套关键字struct Buch { struct Autor a; };结构体套结构体是常态常用—
按值 vs 按指针传参C 库f(p) vs f(&p)大结构体传指针，且能改原值常用函数
数组的结构体关键字struct Punkt ps[10];一批对象；排序用 qsort + 比较函数常用标准库
union关键字union Wert { int i; double d; };同一块内存的多种解释；大小 = 最大成员进阶—
位域关键字unsigned flag : 1;紧凑存标志位，布局由实现决定进阶+表达式
返回结构体关键字struct Punkt make(void)合法但注意拷贝成本；或传指针写入常用函数

输入输出与文件Ein-/Ausgabe

格式化输入输出 + 文件读写；printf 的格式符要背准。

功能关键字 / API用来做什么阶段交叉

预处理器Präprozessor

编译之前先做文本替换：包含、宏、条件编译。

功能关键字 / API用来做什么阶段交叉
#includeC 库<stdio.h> 找系统路径，"x.h" 先找当前目录头文件只是文本插入，插多了会重复定义入门编译

条件编译C 库#ifdef DEBUG、#if、#else、#endif调试输出、平台差异、特性开关常用调试
字符串化与拼接写法#x、a##b写日志宏、生成名字进阶+—
预定义宏C 库__FILE__、__LINE__、__func__自定义日志/断言最有用的三件套进阶调试
#undef、#errorC 库#error 不支持的平台编译期强行中断，比运行时报错早进阶—

标准库与调试Standardbibliothek

C 的标准库很小：字符串、内存、数学、时间、排序；调试靠 gdb 与 sanitizer。

<math.h>C 库sqrt/pow/fabs/floor/ceil（链接 -lm）浮点运算；误差比较用 fabs(a-b) < 1e-9常用编译
<time.h>C 库time()、clock()、strftime计时与格式化时间进阶—

备注 · 易错点 / 取舍 / 顺序

1
scanf("%d") 遇到非数字会卡死
它不消费非法字符，下一次读还是同一个字符。检查返回值，失败时清缓冲（while ((c=getchar()) != '\n' && c != EOF);）。
2
gets 已从标准里删除
用 fgets(buf, sizeof buf, stdin)；它最多读 n-1 个字符并补 \0。
3
sizeof(数组) 只在定义处有效
传给函数后数组退化成指针，sizeof 变成指针大小（8）。长度要另外传。
4
有符号与无符号混用会反直觉
-1 > 0u 为真。长度、下标统一用 size_t。
5
宏必须整体加括号
#define SQ(x) ((x)*(x))；SQ(i++) 会自增两次——有副作用就别用宏。
6
free 之后立刻置 NULL
能挡住大部分双重释放与悬空使用。
7
越界写不会报错
它可能改坏相邻变量、破坏栈帧，然后在几十行之后崩。学习期开 ASan。
8
char 是否有符号是实现定义
要存字节用 unsigned char；<stdint.h> 里的 int8_t 明确是有符号。
9
浮点不能用 ==
fabs(a-b) < 1e-9 才是正确写法；0.1+0.2 != 0.3。
10
-Wall -Wextra 不够就加 sanitizer
gcc -g -O0 -Wall -Wextra -fsanitize=address,undefined 是学习期最好的默认档。
11
学 C 的推荐顺序
①能编译能跑 ②指针与数组 ③内存 ④结构体 ⑤文件 ⑥宏与多文件工程。别跳到回调与位域。
12
C 与 C++ 的分界
C 没有类、没有异常、没有模板、没有 std::string；学完 C 的指针与内存，再看 C++ 的 RAII 会突然通。
